# STONEMACHINE

Сайт-витрина автозапчастей. Покупатель смотрит товар на сайте, а покупает по ссылке на Авито (или любой другой площадке).
Все товары добавляются через закрытую админку.

---

## Выложить сайт на сервер

Понадобится **VPS** на Ubuntu или Debian (хватит самого дешёвого, от 1 ГБ памяти), его **IP** и **пароль root**.

```bash
./deploy.sh
```

Скрипт спросит:

1. IP сервера
2. пользователя (просто Enter — будет `root`)
3. порт (Enter — `22`)
4. пароль от сервера

Дальше он всё сделает сам: поставит Docker, зальёт сайт, создаст базу. В самом конце попросит **придумать логин и пароль для админки** — запишите их.

Первый раз занимает 5–10 минут. Когда увидите «Готово» — сайт открыт по адресу `http://ВАШ-IP`.

> Работает с Linux и macOS. На Windows — запускать из WSL.

## Обновить сайт

Поменяли код — запускаете тот же `./deploy.sh`. Товары, фото и пароли **не пропадут**: они лежат на сервере отдельно от кода.

## Админка

Адрес: `http://ВАШ-IP/admin`

- **Сводка** — сколько товаров на сайте, что требует внимания (нет фото, цены или ссылки), что смотрят чаще всего.
- **Товары** — список с поиском и сортировкой. «● На сайте» и «● В наличии» переключаются одним нажатием. Остальное — в меню «⋯».
  Отметьте галочками несколько товаров — снизу появится панель: скрыть, показать, сменить категорию, удалить.
- **Корзина** — удалённые товары лежат там 30 дней, их можно вернуть.
- **Категории** — порядок меняется стрелками. Новую можно создать и прямо из карточки товара.
- **Настройки** — название, контакты, коды Яндекса/Google, Метрика.
- **Аккаунт** — смена пароля, выход со всех устройств.

### Как заполнять карточку

Обязательно только **название**. Сверху — главное (фото, название, цена, ссылка), остальное в блоках ниже — по желанию.
Кнопка **«Сохранить и добавить ещё»** сразу открывает чистую форму для следующего товара. **Ctrl+S** — сохранить.

| Поле | Что писать |
|---|---|
| Ссылка «Купить» | Ссылка на объявление. Пусто — вместо кнопки будет «Позвонить» |
| Цена | Как удобно: `12500`, `12 500 ₽`, `12.500`. Пусто — «цена по запросу» |
| К цене | «за пару», «договорная», «от» |
| Своя подпись состояния | «Б/у, отличное» — заменит стандартную |
| Фото | Перетащите мышкой. Первое — обложка. Порядок меняется перетаскиванием |
| Характеристики | Любые строки «параметр — значение» |
| Свои разделы | Любые блоки с заголовком: «Комплектация», «Дефекты», что угодно |

В описании и разделах можно оформлять текст:

```
- пункт списка
1. нумерованный пункт
**жирный текст**
https://ссылки-становятся-кликабельными
```

## Забыли пароль от админки

```bash
./deploy.sh --reset-admin
```

Заново спросит логин и пароль. Все старые входы сбросятся.

## Когда появится домен

1. У регистратора домена создайте **A-запись** на IP сервера.
2. Зайдите на сервер и откройте `/opt/stonemachine/.env`, поменяйте три строки:
   ```
   SITE_ADDRESS=ваш-домен.ru
   SITE_URL=https://ваш-домен.ru
   COOKIE_SECURE=true
   ```
3. Запустите `./deploy.sh` ещё раз.

HTTPS-сертификат выпустится сам.

## Яндекс и Google

После подключения домена:

1. Добавьте сайт в [Яндекс.Вебмастер](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console).
2. Способ подтверждения — **мета-тег**. Скопируйте его целиком в админку → Настройки сайта.
3. В вебмастере укажите карту сайта — готовая ссылка лежит в админке справа на странице настроек.

Дальше ничего делать не нужно: новые товары сами попадают в карту сайта, а Яндекс получает уведомление при каждом изменении.

## Резервная копия

На сервере:

```bash
cd /opt/stonemachine
# база
docker compose exec -T db sh -c 'pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB"' > backup-$(date +%F).sql
# фото
docker compose exec -T app tar czf - -C /app/data uploads > photos-$(date +%F).tar.gz
```

Скачать к себе: `scp root@ВАШ-IP:'/opt/stonemachine/*-20*' .`

## Если что-то сломалось

На сервере:

```bash
cd /opt/stonemachine
docker compose ps            # что запущено
docker compose logs app      # ошибки сайта
docker compose restart app   # перезапустить сайт
```

## Для разработчика

Next.js 15 · PostgreSQL · Prisma · Tailwind 4 · Caddy · Docker Compose

```bash
npm install
cp .env.example .env              # поправить DATABASE_URL на свою базу
npx prisma migrate dev            # создать таблицы
npm run db:seed                   # демо-товары (необязательно)
npm run admin:create              # логин/пароль админки
npm run dev                       # http://localhost:3000
```

| Где | Что |
|---|---|
| `src/app/(site)` | витрина: главная, каталог, карточка |
| `src/app/admin` | админка и все действия (`actions.ts`) |
| `src/app/sitemap.ts`, `robots.txt/` | SEO, собираются из базы |
| `prisma/schema.prisma` | структура базы |
| `deploy.sh` | деплой по SSH |
